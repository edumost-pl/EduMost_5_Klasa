# EduMost Lesson Template Map

To **nie** jest makietą UI.

Wspólne (rekomendacja EduMost; GWO = cele, nie ekrany): START → CEL (1–3 can-do z Kryteriów Temat N) → specyfika kategorii → SPRAWDŹ → ZAPAMIĘTAJ.

**Dwujęzyczność:** polecenie i pojęcie po polsku; UA przy pojęciu i przy każdym akapicie do zrozumienia. UA nie zastępuje czytania PL.

## LITERATURA

- **Obowiązkowe:** książka s. N; vocab; tylko punkty siatki **tego** T; dowód w tekście; check.
- **Możliwe:** recytacja; drama LOGIN UNCERTAIN; załącznik.
- **Dwujęzyczne:** pojęcie + akapity robocze + polecenia.
- **Tekst:** CENT (wiersz / mit / proza).
- **Zeszyt:** gdy GWO «zna zasady» albo termin jest celem.
- **Odpowiedź własna:** tak.
- **Kontrola:** wskazanie w tekście.
- **GWO:** Kryteria PUBLIC; Z gdy CLEAR; KN LOGIN.

## LEKTURY

- **Obowiązkowe na T:** fragment + can-do tego T.
- **Możliwe poza T:** cykl L0–L12; scenariusz LOGIN.
- **Dwujęzyczne:** akapity fragmentu.
- **Tekst:** CENT:lektura.
- **Zeszyt:** plan / narrator (wniosek).
- **Odpowiedź własna:** tak.
- **Kontrola:** skills T, nie cała powieść na T62.
- **GWO:** kryteria + scenariusz LOGIN + SPE 7/15.

## GRAMATYKA

- **Obowiązkowe:** pojęcie PL+UA; przykłady; rozpoznanie; kontrast; forma; zdanie; check.
- **Możliwe:** transformacja; tekst podręcznika; typowe błędy (lista GWO NOT_FOUND).
- **Dwujęzyczne:** definicja i «to nie jest Y».
- **Tekst:** supp.
- **Zeszyt:** definicja (+ *nie* gdy w temacie).
- **Odpowiedź własna:** własne zdanie.
- **Kontrola:** rozpoznaj + wstaw formę.
- **GWO:** kryteria + Z + SPE + schematy LOGIN.

## ORTOGRAFIA

- **Obowiązkowe:** RULE → wyjaśnienie → przykłady → rozpoznanie → ćwiczenie → zeszyt → zastosowanie → mini-check.
- **Możliwe:** wyrazy pamięciowe (GWO T7); dyktando (T5/T7); wyjątki z podręcznika.
- **Dwujęzyczne:** objaśnienie reguły; przykłady PL.
- **Tekst:** supp.
- **Zeszyt:** **reguła**.
- **Odpowiedź własna:** uzasadnij pisownię.
- **Kontrola:** mini-check ≠ dyktando szkolne.
- **GWO:** kryteria; Z2/Z3 próbki PUBLIC; Z30/Z42 LOGIN.

## PISANIE

- **Obowiązkowe:** forma, po co, elementy, model, plan, własny tekst, self-check.
- **Możliwe:** redakcja; inscenizacja.
- **Dwujęzyczne:** nazwy elementów; model PL.
- **Tekst:** model w podręczniku.
- **Zeszyt:** schemat formy.
- **Odpowiedź własna:** rdzeń (GWO: redaguje).
- **Kontrola:** can-do Temat N, nie wklejona rubryka.
- **GWO:** kryteria; Z21/Z24–25 LOGIN; checklist PDF NOT_FOUND.

## CZYTANIE

- **Obowiązkowe:** cel; tekst w książce; vocab; znajdź informację; (gdy skill) fakt/opinia lub notatka; check.
- **Możliwe:** głośne czytanie (T4); T1 = sytuacja/plansza, nie artykuł.
- **Dwujęzyczne:** akapity informacyjne / opis sytuacji.
- **Tekst:** CENT:informacyjny / plansza / słownik.
- **Zeszyt:** notatka gdy T4; inaczej opcjonalnie.
- **Odpowiedź własna:** notatka / uzasadnienie.
- **Kontrola:** dowód w zdaniu.
- **GWO:** kryteria; Z4 LOGIN (T9).

## KULTURA_MEDIA

- **Obowiązkowe:** obiekt; na co patrzeć; 2–5 terminów; mała produkcja/opis.
- **Możliwe:** związek z tekstem; scenariusz filmu LOGIN UNCERTAIN.
- **Dwujęzyczne:** terminy + pytania.
- **Tekst:** CENT:tekst kultury (odsyłać do s. N; nie ściągać obrazów bez licencji).
- **Zeszyt:** cechy / terminy.
- **Odpowiedź własna:** opis, plakat, dymki.
- **Kontrola:** nazwij element.
- **GWO:** kryteria; Z36, Z39, Z43 CLEAR.

## NEUTRAL

- **Obowiązkowe:** tylko uczone skills; check.
- **Możliwe:** SPR-R*n* LOGIN poza T.
- **Dwujęzyczne:** polecenia.
- **Tekst:** mix.
- **Zeszyt:** opcjonalne podsumowanie.
- **Odpowiedź własna:** synteza z *Sprawdzę się!*.
- **Kontrola:** bez nowej teorii.
- **GWO:** kryteria powtórek + sprawdzian rozdziału.

## 10. Pilot — 5 T, pięć szablonów

Lekcji **nie tworzymy** teraz.

### T2 — LITERATURA / WIERSZ (*Preludium*, s. 10)

- **Dlaczego:** kryteria konkretne (relacja, nastrój, sytuacja, apostrofa). Sprawdza «nie 15 ekranów»: **bez** wers/rym.
- **GWO:** KRYT T2; brak Z; brak scenariusza 1:1.
- **Cel:** jasny.
- **Elementy:** READ książka → UA strof roboczych → kto/nastrój/apostrofa → evidence → own-response → zeszyt zasad apostrofy → check.

### T29 — GRAMATYKA (odmiana rzeczownika, s. 60)

- **Dlaczego:** pojęcie + formy + *nie* + SPE 4 próbka PUBLIC + Z8/Z9 LOGIN.
- **GWO:** kryteria T29–31; SPE4; Z8/Z9.
- **Cel:** jasny.
- **Elementy:** CONCEPT+UA → recognition → kontrast temat/końcówka i *nie* → forms → sentence → s.60 → own-example → zeszyt → check. T30–T31 = kontynuacja.

### T5 — ORTOGRAFIA (wymiana, s. 16)

- **Dlaczego:** Z2 próbka PUBLIC; GWO: zna regułę, wyjaśnia, stosuje, dyktando.
- **GWO:** KRYT T5 + Z2.
- **Cel:** jasny.
- **Elementy:** pełny łańcuch ORT; zeszyt = reguła.

### T84 — PISANIE (list oficjalny, s. 181)

- **Dlaczego:** elementy w kryteriach (nadawca, adresat, temat, cel, układ) + Z24–25 + SPE11.
- **GWO:** KRYT T84; Z LOGIN; checklist NOT_FOUND.
- **Cel:** jasny.
- **Elementy:** warsztat FORM; model w książce; checklista EduMost z kryteriów; własny list.

### T4 — CZYTANIE (*Doskonalimy czytanie*, s. 14)

- **Dlaczego:** czysty READING (nie literatura). Informacja, notatka, głośne czytanie, fakt/opinia.
- **GWO:** KRYT T4; brak Z. Przy pisaniu lekcji wrócić do PDF (skład kolumn psuje automatyczny wyciąg).
- **Cel:** jasny w katalogu/PDF.
- **Elementy:** READ s.14 → vocab → find-info → fact/opinia → notatka → check. Głośne czytanie poza silnikiem choice.

**Nie w pilocie:** T62 (cykl lektury); T12 komiks jako ewentualny 6. szablon KULTURA_MEDIA.
