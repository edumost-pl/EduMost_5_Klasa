podzielność

подільність

a jest podzielne przez b  ⇔  a : b bez reszty

PL: Czy dzielenie wychodzi „na czysto”.

UA: Чи ділення виходить без остачі.

dzielnik liczby

дільник числа

dzielniki 12: 1,2,3,4,6,12

PL: Liczba, przez którą dana liczba dzieli się bez reszty.

UA: Число, на яке дане число ділиться без остачі.

wielokrotność

кратне

wielokrotności 5: 5,10,15,20…

PL: Wynik mnożenia liczby przez liczbę naturalną.

UA: Добуток числа на натуральне число.

liczba pierwsza

просте число

2, 3, 5, 7, 11…

PL: Ma dokładnie dwa dzielniki: 1 i sama siebie.

UA: Має рівно два дільники: 1 і саме себе.

liczba złożona

складене число

4, 6, 8, 9, 10…

PL: Ma więcej niż dwa dzielniki.

UA: Має більше ніж два дільники.

NWD / NWW

НСД / НСК

NWD = największy wspólny dzielnik
NWW = najmniejsza wspólna wielokrotność
НСД / НСК

PL: NWD = największy wspólny dzielnik; NWW = najmniejsza wspólna wielokrotność.

UA: НСД = найбільший спільний дільник; НСК = найменше спільне кратне.

cechy podzielności

ознаки подільності

przez 2: ostatnia cyfra parzysta
przez 5: 0 lub 5
przez 10: 0

PL: Szybkie reguły bez pełnego dzielenia.

UA: Швидкі правила без повного ділення.
