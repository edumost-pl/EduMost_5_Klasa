# Как писать экран урока

Один экран — один объект в массиве `blocks`. Порядок объектов — порядок экранов.

Поля пишутся как JSON: польский и украинский рядом, списки массивами, выделение — звёздочками в строке или отдельным объектом.

```json
{
  "blocks": [
    {
      "type": "concept",
      "heading": { "pl": "Co to jest mapa?", "ua": "Що таке карта?" },
      "text": {
        "pl": ["Mapa to rysunek okolicy z góry."],
        "ua": ["Карта — це малюнок околиці згори."]
      }
    }
  ]
}
```

`heading` — заголовок экрана. Если его нет, плеер подставит свой короткий заголовок по `type`.

## Текст

Почти все надписи — объект с двумя языками:

```json
{ "pl": "Zdanie po polsku.", "ua": "Речення українською." }
```

Украинский виден, когда включён язык UA. Польский виден всегда.

Несколько абзацев — массив. Один элемент массива — один абзац. Число абзацев в `pl` и `ua` должно совпадать: они стоят парами.

```json
"text": {
  "pl": [
    "Pierwszy akapit.",
    "Drugi akapit."
  ],
  "ua": [
    "Перший абзац.",
    "Другий абзац."
  ]
}
```

## Как выделить слово

Два вида. Оба пишутся прямо в строке.

| В JSON | На экране |
|---|---|
| `**mapa**` | слово цветом, жирное. Так отмечают термин |
| `*mapa*` | просто жирное, цвет текста не меняется |

```json
"text": {
  "pl": ["**Mapa** to rysunek z góry, a *zdjęcie* zostaje zdjęciem."],
  "ua": ["**Карта** — це малюнок згори, а *фото* лишається фото."]
}
```

Звёздочки не вкладывают друг в друга. Один фрагмент — одна пара.

Если слово надо вставить в середину фразы отдельным куском, абзац становится массивом внутри массива. Внутренний массив склеивается в один абзац.

```json
"text": {
  "pl": [
    [
      { "text": "Mapa", "emphasis": true },
      " to rysunek okolicy z góry."
    ]
  ],
  "ua": [
    [
      { "text": "Карта", "emphasis": true },
      " — це малюнок околиці згори."
    ]
  ]
}
```

`emphasis: true` — то же, что `**слово**`: цвет и жирный. `bold: true` — то же, что `*слово*`: только жирный.

Подсветить готовое слово внутри целой фразы:

```json
{ "text": "Skala jest na dole kartki.", "mark": "Skala" }
```

`mark` может быть одним словом или массивом слов. Каждое вхождение становится цветным.

## Какие блоки и зачем

`type` говорит, зачем этот экран. Картинка, текст, список и вопрос у большинства блоков одни и те же. Отличаются три: `goal`, `vocabulary`, `mistake`.

| `type` | Зачем экран | Что обязательно |
|---|---|---|
| `intro` | вход в урок | `heading`, `text` |
| `observe` | смотрим картинку или текст и замечаем сами | `visual` или `text` |
| `concept` | одно новое правило | `text`. Часто ещё `items` |
| `example` | разбор по шагам | `steps` |
| `algorithm` | шаги по порядку | `steps` или `items` |
| `guided-practice` | короткий вопрос вместе. Здесь можно дать подсказку | `task` и `task.hint` |
| `practice` | сам, на новых данных. Подсказки нет | `task` без `hint` |
| `check` | проверка. Подсказки нет | `task` без `hint` |
| `mistake` | чужая ошибка. Плеер сам пишет «Nie.» / «Ні.» | `claim`, потом `text` |
| `summary` | что запомнить. Пункты списка с галочками | `items` |
| `goal` | что уметь к концу. Пункты с пустым квадратом | `items` |
| `vocabulary` | словарик: слово и пояснение | `rows` |
| `comparison` | два случая рядом | `text` или `items` |
| `classification` | группы. Список в рамке | `items` |
| `problem` | задача | `task` |
| `challenge` | труднее основной линии | `task` |
| `visual` | на экране главное — картинка | `visual` |
| `review` | повтор | `items` или `text` |
| `reflection` | вопрос к себе | `text` или `task` |

Обычный экран объяснения:

```json
{
  "type": "concept",
  "heading": { "pl": "Co to jest mapa?", "ua": "Що таке карта?" },
  "visual": {
    "kind": "image",
    "file": "./img/para.png",
    "alt": { "pl": "Zdjęcie obok mapy", "ua": "Фото поруч із картою" }
  },
  "text": {
    "pl": ["**Mapa** to rysunek z góry."],
    "ua": ["**Карта** — це малюнок згори."]
  },
  "items": [
    { "pl": "Tytuł nazywa cały obszar.", "ua": "Заголовок називає всю територію." },
    { "pl": "Legenda tłumaczy znaki.", "ua": "Легенда пояснює знаки." }
  ]
}
```

Ребёнок видит сверху вниз: заголовок, картинку, абзацы, затем список. Вопрос, если он есть, стоит последним.

### Ошибка

`claim` — ложная фраза. Под ней плеер сам ставит «Nie.» Плеер не выбирает за ребёнка букву ответа.

```json
{
  "type": "mistake",
  "heading": { "pl": "Typowy błąd", "ua": "Типова помилка" },
  "claim": {
    "pl": "„Mapa to zwykłe zdjęcie.”",
    "ua": "«Карта — це звичайна фотографія.»"
  },
  "text": {
    "pl": ["Mapa jest rysunkiem z góry i ma znaki."],
    "ua": ["Карта є малюнком згори і має знаки."]
  }
}
```

### Шаги примера

Пока у блока есть `steps`, картинка на самом блоке не показывается. Её кладут внутрь первого шага.

`reveal: true` — сначала виден первый шаг, дальше кнопка «следующий шаг».

```json
{
  "type": "example",
  "heading": { "pl": "Przykład", "ua": "Приклад" },
  "reveal": true,
  "steps": [
    {
      "visual": {
        "kind": "image",
        "file": "./img/para.png",
        "alt": { "pl": "Dwa obrazki", "ua": "Два зображення" }
      },
      "text": {
        "pl": ["Najpierw patrzysz na zdjęcie."],
        "ua": ["Спочатку дивишся на фото."]
      }
    },
    {
      "text": {
        "pl": ["Potem patrzysz na mapę."],
        "ua": ["Потім дивишся на карту."]
      }
    }
  ]
}
```

### Словарик

Две колонки. Слева польское слово, справа пояснение. Вторая колонка видна всегда, язык переключать не нужно.

```json
{
  "type": "vocabulary",
  "heading": { "pl": "Słowniczek", "ua": "Словарик" },
  "rows": [
    { "pl": "mapa", "ua": "Рисунок местности сверху. Это не фотография." },
    { "pl": "legenda", "ua": "Знак рядом со словом. Сначала смотри сюда." }
  ]
}
```

### Цель

```json
{
  "type": "goal",
  "heading": { "pl": "Po lekcji potrafię", "ua": "Після уроку вмію" },
  "items": [
    { "pl": "Wskazać tytuł mapy.", "ua": "Показати заголовок карти." },
    { "pl": "Odczytać legendę.", "ua": "Прочитати легенду." }
  ]
}
```

## Список

Поле `items`. Каждый элемент — один пункт маркированного списка. Внутри пункта тот же текст, что и в абзаце: строка или объект `{ "pl", "ua" }`, со звёздочками.

```json
"items": [
  { "pl": "**Tytuł** nazywa obszar.", "ua": "**Заголовок** називає територію." },
  { "pl": "**Legenda** tłumaczy znaki.", "ua": "**Легенда** пояснює знаки." }
]
```

У `summary` у пунктов галочки. У `classification` список в рамке. У `goal` вместо точек пустые квадраты. Пишется одинаково, через `items`.

## Правило

Карточка с заголовком «Reguła». Стоит выше текста и картинки.

```json
"rule": {
  "pl": [
    "*Podmiot liryczny* mówi w wierszu „ja”.",
    "*Adresat* to ten, do kogo się zwraca."
  ],
  "ua": [
    "*Ліричний герой* говорить у вірші «я».",
    "*Адресат* — той, до кого звертаються."
  ]
}
```

В математике правило выглядит иначе и лежит внутри `parts`, не на корне экрана:

```json
"parts": [
  {
    "rule": {
      "label": { "pl": "Zapamiętaj", "ua": "Запам’ятай" },
      "lines": {
        "pl": "DZIELĘ → MNOŻĘ → ODEJMUJĘ → SPROWADZAM",
        "ua": "ДІЛЮ → МНОЖУ → ВІДНІМАЮ → СПУСКАЮ"
      }
    }
  }
]
```

В `lines` звёздочки не работают: это одна готовая строка. `type` при этом остаётся обычным, например `concept`. Отдельного типа `parts` нет.

## Картинка

```json
"visual": {
  "kind": "image",
  "file": "./img/nazwa.png",
  "alt": { "pl": "Co widać na obrazku", "ua": "Що видно на малюнку" },
  "title": { "pl": "Krótki tytuł", "ua": "Короткий заголовок" }
}
```

`file` начинается с `./` и лежит в папке `img` этого урока. `alt` — подпись для того, кто не видит картинку. По нажатию картинка открывается на весь экран целиком, без обрезки.

Если картинки ещё нет, вместо неё заглушка с заданием для рисунка:

```json
"visual": {
  "kind": "image-placeholder",
  "title": { "pl": "Cztery części definicji", "ua": "Чотири частини визначення" },
  "prompt": {
    "pl": "Infografika: na środku uproszczona mapa, wokół cztery karty z jednym zdaniem.",
    "ua": "Інфографіка: посередині спрощена карта, навколо чотири картки з одним реченням."
  }
}
```

На заглушке не ставят вопрос, ответ на который можно прочитать только с будущей картинки.

## Видео

Только YouTube.

```json
"visual": {
  "kind": "youtube",
  "id": "Nody3LlwVP0",
  "title": { "pl": "Posłuchaj wiersza", "ua": "Послухай вірш" }
}
```

`id` — 11 знаков из ссылки или сама ссылка на ролик.

## Вопрос

Поле `task` на том же экране. Для выбора одного ответа правильный вариант всегда с `"id": "a"`. На неправильные есть `mistakes`: что пересмотреть, без названия буквы. Подсказка `hint` только на `guided-practice`.

```json
"task": {
  "id": "g02-s1",
  "type": "single-choice",
  "question": { "pl": "Co przedstawia mapa?", "ua": "Що зображує карта?" },
  "options": [
    { "id": "a", "label": { "pl": "Miejsce z góry, pokazane znakami.", "ua": "Місце згори, показане знаками." } },
    { "id": "b", "label": { "pl": "Zdjęcie z brzegu.", "ua": "Фото з берега." } },
    { "id": "c", "label": { "pl": "Tylko budynki z boku.", "ua": "Лише будівлі збоку." } }
  ],
  "answer": "a",
  "hint": { "pl": "Porównaj, z której strony patrzysz.", "ua": "Порівняй, з якого боку ти дивишся." },
  "mistakes": [
    {
      "answer": "b",
      "feedback": { "pl": "Zdjęcie zostaje widokiem z brzegu. Wróć do kartki z góry.", "ua": "Фото лишається виглядом з берега. Повернися до аркуша згори." }
    },
    {
      "answer": "c",
      "feedback": { "pl": "Na mapie jest też jezioro. Wróć do znaków.", "ua": "На карті є ще озеро. Повернися до знаків." }
    }
  ],
  "explanation": {
    "pl": "Mapa pokazuje miejsce z góry znakami.",
    "ua": "Карта показує місце згори знаками."
  }
}
```

`explanation` ребёнок видит только после верного ответа.

Короткий ответ своими словами — `"type": "open-answer"`. В `answer` список целых фраз, которые засчитываются. Сверяется всё предложение, не отдельное слово внутри него.

```json
"task": {
  "id": "g02-s12",
  "type": "open-answer",
  "question": { "pl": "Napisz po polsku jedno zdanie.", "ua": "Напиши польською одне речення." },
  "answer": ["w legendzie krzyż oznacza kościół", "bo tak jest w legendzie"],
  "explanation": { "pl": "W legendzie krzyż oznacza kościół.", "ua": "Досить короткого польського речення." }
}
```
