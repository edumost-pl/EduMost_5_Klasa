dodawanie

додавання

a + b = c

сума

odjemna / odjemnik

зменшуване / від’ємник

odjemna − odjemnik = różnica
зменшуване − від’ємник = різниця

PL: Odjemna = od czego odejmujemy; odjemnik = ile odejmujemy.

UA: Зменшуване = від чого віднімаємо; від’ємник = скільки віднімаємо.
